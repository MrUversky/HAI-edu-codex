# Demo Role Brief

## Роль

`Lead Backend Engineer для AI-продукта`

## Контекст

Это учебная demo-вакансия для воркшопа.  
Нужен сильный backend-инженер или technical lead, который может:

- взять на себя сложную серверную часть продукта
- довести решения от system design до production
- уверенно работать в небольшом продукте с высокой неопределённостью
- помогать команде принимать технические решения

## Обязательные требования

- 7+ лет в backend или platform engineering
- опыт проектирования и запуска production-сервисов
- уверенный Python и/или Go
- опыт с SQL-базами и data-инфраструктурой
- опыт работы с cloud-инфраструктурой
- понимание observability, reliability и incident response
- способность самостоятельно вести кусок системы, а не только выполнять узкие задачи

## Желательные сигналы

- опыт в AI-enabled продуктах или internal AI tooling
- опыт mentoring / hiring / technical leadership
- опыт в стартапах, консалтинге или продуктовой среде с высокой скоростью изменений
- опыт с Telegram bots, MCP, automation workflows или developer tooling

## Что будет сигналом риска

- только узкий enterprise execution без ownership
- слабый опыт production-систем
- отсутствие evidence, что человек умеет доводить технические решения до реального запуска
- профиль сильно уходит в pure founder / advisor без hands-on engineering

## Что хотим получить на выходе из оценки

- короткую scorecard по кандидату
- match / partial match / low match относительно этой роли
- одну рекомендацию:
  - `позвать на следующий шаг`
  - `нужно уточнение`
  - `пока не приоритет`
