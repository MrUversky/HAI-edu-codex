# Facilitator Script

## Core lesson logic
1. setup and light personalization
2. observe the shared case
3. unpack the architecture
4. touch the mechanism in mini-practice
5. create or adapt one agent
6. validate it
7. define one realistic personal next step

## Key facilitation rules
- do not ask for a full personal business case too early
- keep participants from overengineering
- protect the difference between setup, practice, and personal application
- redirect broad transformation talk into one bounded pilot

## If participants get lost
Ask:
- what is the input?
- what is the output?
- who owns the result?
- where does AI help?
- where should a human still decide?
