# Что Делать После Урока

Если участник хочет продолжить самостоятельно, маршрут должен быть коротким и реалистичным.

1. Открой одного агента.
Рекомендуемый файл: [resume-processing-agent.toml](/Users/Igor/DemoHAI_V1/.codex/agents/resume-processing-agent.toml)

2. Открой два skill.
Рекомендуемые файлы:
- [send-telegram-message/SKILL.md](/Users/Igor/DemoHAI_V1/.agents/skills/send-telegram-message/SKILL.md)
- [extract-meeting-actions/SKILL.md](/Users/Igor/DemoHAI_V1/examples/reference_skills/extract-meeting-actions/SKILL.md)

3. Определи одну повторяющуюся рабочую ситуацию.

4. Выбери один источник.
Например:
- письмо
- meeting notes
- документ
- экспорт из системы

5. Опиши один желаемый результат.
Например:
- markdown summary
- список задач
- короткое сообщение в чат

6. Создай свой первый новый skill по шаблону.
Открой [new_skill_template.md](/Users/Igor/DemoHAI_V1/templates/new_skill_template.md) и используй его как контракт.
