# Use Cases

## Demo use case

Кейс для показа:
- приходит письмо с резюме
- агент выбирает письмо
- skills выделяют нужную информацию и оценивают кандидата
- итог уходит в Telegram

Задача demo:
- показать силу orchestration
- показать, что агент управляет процессом целиком

## Exercise use case

Кейс для практики:
- есть сырой текст встречи
- нужно выделить задачи, вопросы и риски
- затем сохранить структурированный результат
- потом отправить только задачи в Telegram

Задача exercise:
- показать, как добавить один новый skill поверх готовой архитектуры
- не перегружать участника второй сложной интеграцией
- не заставлять участника повторять teacher demo у себя

## Что не является целью этого repo

- production-ready система
- тяжёлая автоматизация
- универсальный агент на всё
- скрытый orchestration без читаемых контрактов
