# Режимы Запуска

В этом repo есть два разных старта урока.

## 1. Режим преподавателя

Команда:

`Запусти урок для преподавателя`

Что должно произойти:
- короткий setup
- переход к карте мира
- полный demo-поток `Gmail -> fetch -> evaluate -> Telegram`
- короткий разбор архитектуры после demo

## 2. Режим участника

Команда:

`Запусти урок для участника`

Что должно произойти:
- короткий setup
- переход к карте мира
- сразу переход к exercise
- чат с короткими вопросами
- prompt для `/skill-creator`
- review результата
- запуск созданного skill
- показ результата на экране, сохранение в файл и Telegram step

## Почему режимов два

Преподавателю нужен полный прогон.

Участнику не нужно заново проходить тот же Gmail/Telegram demo. Ему нужно быстрее перейти к созданию своего первого skill.
