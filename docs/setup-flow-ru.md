# Setup Flow

## Зачем нужен setup

Setup нужен для лёгкой персонализации без раннего ухода в личный рабочий кейс.

## Как запускать

Команды старта:

- `Запусти урок для преподавателя`
- `Запусти урок для участника`

## Что должен сделать Codex

1. Коротко объяснить маршрут урока.
2. Начать с setup.
3. Задавать по одному вопросу за раз.
4. Собрать и сохранить `participants/<name>/participant_setup.md`.
5. После сохранения перейти:
   - в teacher flow: к concepts и demo
   - в student flow: к concepts и exercise

## Какие вопросы нужно собрать

- `Как тебя зовут?`
- роль или функция
- уровень знакомства с AI
- стиль объяснений:
  1. коротко и по шагам
  2. сначала схема, потом детали
  3. с примерами на каждом этапе
- главная цель на урок

## Что не делать на setup

- не просить полный рабочий кейс
- не уходить в детали интеграций
- не превращать setup в brainstorming
