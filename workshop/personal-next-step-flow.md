# Personal Next Step Flow

Goal: only after shared case, architecture unpacking, create/adapt skill, and validation, identify one realistic next step for the participant.

Stage framing:
- Current stage: `personal next step`
- What is already done: skill draft and validation
- What we are doing now: narrow the outcome to one realistic first move
- Expected artifacts:
  - `participants/<name>/personal_next_step.md`
  - `participants/<name>/final_action_card.md`

Participant-facing start:
- `помоги мне определить следующий шаг`
- `давай сформулируем мой personal next step`

Save:
- personal_next_step.md
- final_action_card.md

Run this stage as a guided workflow:
- announce the final stage explicitly;
- if the participant uses a short command, interpret it through `workshop/dispatch-catalog.md`;
- ask one short question at a time;
- use the participant's role, selected skill, and validation context;
- draft `personal_next_step.md` first;
- then derive `final_action_card.md`.

Questions should focus on:
- one repeating work situation,
- the usual inputs in that situation,
- what is still done manually,
- what repeats enough to justify a first test,
- one bounded first scenario,
- what success would look like in the next 7 days.

Do not drift into full transformation strategy.
