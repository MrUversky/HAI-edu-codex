# Create or Adapt Agent Flow

Goal: participants either:
1. create one elective agent from a template,
2. or adapt an existing elective agent to their own context.

Required outputs:
- agent spec,
- tool or integration assumptions,
- guardrails,
- validation report,
- final submission package.

Important:
- live integrations are optional; stubbed integrations must be labeled clearly;
- validation is mandatory before final submission.
