# Task Register

## First sprint goal
Use the workshop repository to run one grounded skill-based workshop session that turns messy planning inputs into a bounded, reviewable first pilot.

## In-scope tasks
- confirm the lesson route and participant pacing
- prepare the shared-case input packet
- run the shared-case skill chain end to end
- explain why each skill exists and what artifact it hands off
- create one bounded participant skill draft
- run validation and produce a validation report
- end with one realistic participant next step

## Out-of-scope tasks
- live enterprise integrations
- automatic write-back to external systems
- full company AI strategy design
- complex observability or production telemetry

## Owner placeholders
- facilitator owner placeholder
- shared-case runtime owner placeholder
- validation owner placeholder
- participant support owner placeholder

## Dependencies and blockers
- one working Codex path
- approved shared-case artifacts
- clear workshop pacing
- explicit fallback if live demonstration breaks

## First review checkpoint
After the shared-case chain and before skill creation, review whether participants understand:
- what each skill did
- what artifact each step produced
- where human review stayed in the loop

## Sprint success criteria
- the lesson runs end to end without losing the stage structure
- the participant understands the shared-case chain
- one bounded skill is drafted and validated
- one realistic next step is captured at the end
