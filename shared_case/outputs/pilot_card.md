# Pilot Card

## Pilot use case
Use a Codex-guided workshop repo to help mixed-function participants understand agent workflows, create or adapt one bounded agent, validate it, and leave with one realistic next step.

## Why this first
This pilot is strong because it:
- demonstrates agent systems in a grounded way
- creates direct participant value in one session
- avoids the need for heavy live integrations
- produces inspectable artifacts
- creates a natural bridge to deeper work

## Scope boundaries
### In scope
- local or repo-based Codex experience
- shared-case demo
- mini-practice
- create or adapt one elective agent
- validator pass
- final personal action card

### Out of scope for V1
- full live enterprise integrations
- real write-back into external systems
- broad company-wide strategy design
- complex telemetry or production observability stack

## What is needed to start
- lesson repo with shared case and templates
- one working Codex entry path
- participant templates
- validator pipeline
- facilitator recovery plan

## Success criteria
- participant understands how the workflow operates
- participant successfully creates or adapts one agent
- participant receives a validation result
- participant leaves with one realistic next step
- facilitator can recover if demo tooling fails

## Next step after pilot
If the lesson works, the next step is to add:
- more practice datasets
- optional live stubs for selected integrations
- lightweight submission scoring storage
- a cleaner facilitator dashboard
