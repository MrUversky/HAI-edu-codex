# Workflow Draft

## Workflow goal
Move the lesson from abstract AI interest to one realistic next step per participant, without overloading the audience too early.

## Recommended lesson sequence

### Step 1. Setup and light personalization
AI or Codex asks a few questions about role, familiarity, and preferred interaction style.

**Human owns:** comfort, pacing, onboarding tone.
**AI helps with:** setup capture and adaptation of explanation style.

### Step 2. Shared case demo
Run the common case through:
- Intake Agent
- Analysis Agent
- Workflow Agent
- Experiment Agent

**Human owns:** framing and interpretation.
**AI helps with:** transformation across the four outputs.

### Step 3. Architecture unpacking
Explain what each agent did, why the flow worked, and how it connects to maturity.

**Human owns:** teaching and deconstruction.
**AI helps with:** surfacing structure and examples on demand.

### Step 4. Mini-practice
Participants run one small transformation on reduced shared material.

**Human owns:** exercise framing, scope control, troubleshooting.
**AI helps with:** the actual transformation and output formatting.

### Step 5. Create or adapt an agent
Participants choose one elective agent and either create it from template or adapt it.

**Human owns:** helping participants avoid overengineering.
**AI helps with:** drafting the spec and integration assumptions.

### Step 6. Validation
Run the validation layer:
- agent curator
- skill curator
- safety validator
- architecture validator
- eval orchestrator

**Human owns:** judgment on borderline cases.
**AI helps with:** structured review and scoring.

### Step 7. Personal next step
Only after all prior steps, identify one realistic pilot for the participant's own context.

**Human owns:** realism and prioritization support.
**AI helps with:** reflection structure and action-card drafting.

## Critical checkpoints
- participant does not get pushed into a personal use case too early
- shared case stays central enough to teach mechanics
- create/adapt practice stays bounded
- validation is mandatory before submission
- final output is one realistic next step, not a transformation roadmap

## What makes this repeatable
- explicit lesson stages
- explicit agent roles
- reusable shared-case inputs
- reusable elective agent templates
- reusable validator pipeline
- reusable participant templates
