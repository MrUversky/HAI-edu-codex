# Constraints

- продолжительность урока: 2 часа
- аудитория смешанная по функциям и уровню подготовки
- нельзя требовать технических навыков
- желательно показать agent / workflow logic
- нужен сильный live-demo
- после урока у участника должен остаться конкретный следующий шаг
- у команды ограниченное время на подготовку
- рабочая версия урока нужна через 10 дней
- нельзя делать слишком сложную инфраструктуру ради одного демо
- важно оставить мост в более глубокую программу / пилот
