# Evaluation Rubric

Score each category from 1 to 5.

## 1. Role clarity
1 = vague
5 = role is explicit and bounded

## 2. Usefulness
1 = unclear practical value
5 = obvious practical value in a real workflow

## 3. Scope discipline
1 = too broad or confused
5 = tight first-pilot scope

## 4. Structure
1 = outputs are vague
5 = outputs are explicit and chainable

## 5. Safety
1 = no guardrails or unsafe assumptions
5 = clear guardrails and human checkpoints

## 6. Architecture fit
1 = wrong pattern or overengineered
5 = appropriate pattern for the task

## 7. Validation quality
1 = no serious validation path
5 = validation is explicit and meaningful
