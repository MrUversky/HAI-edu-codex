# Skill Spec Template

## Skill name

## Purpose
What repeated situation does this skill help with?

## Trigger phrases
What would a participant or user say that should activate this skill?

## Inputs
What does the skill read?

## Outputs
What should the skill produce or save?

## Human review point
Where must a person approve, confirm, or correct the result?

## Fallback or integration notes
If an external system is involved, what is real and what is still a fallback or stub?

## Canonical layout
- Skill folder: `.agents/skills/<skill-name>/`
- Required file: `.agents/skills/<skill-name>/SKILL.md`
- Optional references: `.agents/skills/<skill-name>/references/`
- Optional scripts: `.agents/skills/<skill-name>/scripts/`
- Validation report: `.agents/skills/<skill-name>/validation_report.md`

## Guardrails
What must the skill not do?

## Success conditions
How will we know this skill is useful?

## Out of scope
What should this skill explicitly not try to do?
