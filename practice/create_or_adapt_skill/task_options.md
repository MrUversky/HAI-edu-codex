# Create or Adapt Skill: Task Options

Choose one bounded scenario:

## Option 1. Telegram Digest
Use when a person or team is overwhelmed by one Telegram chat or channel.

Typical input:
- exported chat history,
- or a clearly specified Telegram group/channel path for a later integration guide.

Typical output:
- grouped themes,
- notable updates,
- watch items,
- action items,
- unanswered questions.

## Option 2. Review Monitor
Use when a team needs to turn messy reviews or feedback into a cleaner signal layer.

Typical input:
- exported reviews,
- copied comments,
- support feedback bundles,
- survey comments.

Typical output:
- signal clusters,
- urgency flags,
- what changed,
- suggested follow-up buckets.

## Option 3. Notion Sync
Use when a team already has structured outputs and wants to lay them out in a Notion-ready format.

Typical input:
- approved tasks,
- project summary,
- owner placeholders,
- next steps.

Typical output:
- Notion-ready records,
- proposed fields,
- status mapping,
- follow-up questions before write-back.

## Option 4. Resume Analysis
Use when an HR or recruiting workflow needs one structured pass over resumes for a specific vacancy.

Typical input:
- one vacancy or role description,
- criteria for that vacancy,
- one resume or a bounded batch of resumes,
- optional interviewer or recruiter notes.

Typical output:
- normalized candidate summary,
- fit signals,
- open questions,
- risk flags,
- next review recommendation.
