# Create or Adapt Agent: Task Options

Choose one:

## Option 1. Review Monitor Agent
Monitors reviews or feedback across selected sources and produces:
- signal clustering
- urgency flagging
- weekly digest
- escalation suggestions

## Option 2. Notion Sync Agent
Transforms notes or requests into structured Notion-ready entries with field mapping assumptions.

## Option 3. Telegram Digest Agent
Collects selected Telegram channel or chat updates and creates a useful digest by theme or action required.

## Option 4. Analytics Insight Agent
Turns weekly metrics exports into a short insight memo:
- anomalies
- likely causes
- questions
- suggested next checks
