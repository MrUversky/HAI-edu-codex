# Notion Sync Scenario Guide

## Best fit
Use when the main workflow already produced structured outputs and the team wants to lay them out in a Notion-ready format.

## Required context
- what approved outputs should be synced
- what final structure is expected
- whether the workshop uses:
  - Notion-ready draft only
  - or a future guided integration path

## Input sources
- approved tasks
- project summary
- owner placeholders
- next steps

## Output contract
- Notion-ready records
- proposed fields
- status mapping
- follow-up questions before write-back

## Human review point
A person reviews the mapped records before any real Notion write-back.

## Fallback and integration path
- default workshop mode: Notion-ready draft only
- optional advanced path: guided MCP or API integration notes
- never imply live write access unless it is actually available

## Canonical layout
- `.agents/skills/notion-sync/SKILL.md`
- optional `.agents/skills/notion-sync/references/`
- optional `.agents/skills/notion-sync/scripts/`
- optional `.agents/skills/notion-sync/integration_notes.md`
