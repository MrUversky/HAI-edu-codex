# Fetch Gmail Resumes

## Goal

Найти одно или несколько подходящих новых писем в Gmail и превратить их в компактный пакет кандидатов для дальнейшей оценки.

## Inputs

- живой Gmail connector
- одно или несколько новых писем с резюме, CV или кратким описанием кандидата
- при необходимости: вложение, pasted text или текст письма

## Outputs

- черновик пакета кандидатов в `drafts/demo/resume_review_draft.md`
- компактная структурированная выжимка по каждому кандидату

## Success Criteria

- выбран bounded batch, а не бесконечный поток писем
- у каждого кандидата выделены ключевые факты
- пакет пригоден для следующего skill без дополнительных догадок

## Out of Scope

- полная ATS-система
- юридическая проверка документов
- массовая автоматическая классификация всей почты

## Procedure

1. Найди одно подходящее новое письмо или небольшой пакет писем с резюме.
2. Не тяни весь inbox.
3. Для каждого письма вытащи:
   - имя кандидата
   - роль или желаемую позицию
   - ключевой опыт
   - заметные навыки
   - сигналы риска или неопределённости
4. Собери результат в компактный markdown draft.
5. Сохрани draft в `drafts/demo/resume_review_draft.md`.

## Human Review

Если письмо неоднозначное или там нет резюме, явно скажи это в артефакте и не притворяйся, что данных достаточно.
